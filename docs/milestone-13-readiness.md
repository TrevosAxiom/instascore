# Milestone 13 Readiness Checklist

Milestone 12 is ready for approval when:

- [x] Fantasy foundation migration exists.
- [x] Fantasy game, season, gameweek, position, player-pool, squad, squad-player and squad-history tables exist.
- [x] Public fantasy-game and player-pool APIs exist.
- [x] Authenticated squad read/save/submit APIs exist.
- [x] Server validates budget, squad size, formation, position constraints, team limits, deadline, captain and vice-captain.
- [x] Revision conflicts are rejected safely.
- [x] React fantasy dashboard and squad-builder foundation are routable at `/fantasy`.
- [x] Fantasy administration foundation is routable at `/admin/fantasy`.
- [x] Frontend linting, type checks, tests and production build pass.
- [ ] PHP syntax and PHPUnit must be run in an environment with PHP/Composer available.
- [ ] Manual QA should seed realistic fantasy gameweek/player-pool data before approval.

Do not begin Milestone 13 until Milestone 12 schema, server validation and manual QA are approved.
