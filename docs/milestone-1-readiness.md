# Milestone 1 entry checklist (historical)

This checklist was satisfied or superseded by Milestone 1 implementation:

- [ ] Milestone 0 lint, typecheck, unit tests and production build pass.
- [ ] PHP 8.2+ and Composer 2 are available locally or in the agreed container.
- [ ] Repository boundary and CI provider are accepted.
- [ ] WordPress minimum version and target hosting limits are confirmed.
- [ ] Canonical app URL and SPA mount strategy (dedicated page/shortcode) are confirmed.
- [ ] ADR-0001 and the migration-ledger approach are accepted.
- [ ] Route, screen and component maps are accepted.
- [ ] Logo usage rights and visual reference are confirmed.
- [ ] Authentication/nonce approach and role naming are accepted.
- [ ] No secrets exist in Git history or frontend environment variables.
- [x] Migration version began at `0`; migration `0001` is now implemented.
- [ ] Milestone 1 scope remains limited to bootstrap, migration runner, REST
      namespace, SPA mount/shell, theme, routing, API/auth infrastructure and
      protected-route foundations.
