# Milestone 15 Readiness Checklist

Milestone 14 is ready for approval when the following are accepted:

- Unified `/operations` dashboard is routable and protected.
- Operations dashboard aggregates system counts, failed jobs, conflicts, audit-log samples and health data.
- Feature flags, maintenance mode, retention settings and emergency notification disable are stored server-side.
- Manual operational actions are permission protected and recorded.
- Diagnostic exports are redacted.
- Frontend formatting, linting, type checking, tests and production build pass.

Recommended Milestone 15 focus:

- Finalise the full data-export catalogue.
- Add richer role and assignment management UI.
- Connect manual operations to observable background job progress.
- Expand server-side pagination for large operational logs.
- Define production maintenance-mode behaviour.
- Add PHP integration tests once PHP/Composer are available in the local environment.
