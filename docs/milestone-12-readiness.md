# Milestone 12 Readiness Checklist

Milestone 11 is ready for review before Milestone 12 when the following are accepted:

- [x] Authenticated follow/unfollow exists for teams, competitions and players.
- [x] Anonymous local favourites are stored and migrated after login.
- [x] Server-side favourites, preferences, personal feed, search and alert-history endpoints exist.
- [x] OneSignal targeting tags are updated after follow/unfollow.
- [x] Future related alerts are suppressible after unfollow.
- [x] Notification preference centre includes timezone, language and preferred-sports foundations.
- [x] Favourites and search pages are provisioned and routable.
- [x] Frontend linting, type checks, tests and production build pass.
- [ ] PHP syntax and PHPUnit must be run in an environment with PHP/Composer available.
- [ ] Manual browser QA should confirm WordPress page provisioning on `http://instascore.local/`.

Do not begin Milestone 12 until the Milestone 11 report, database migration and manual QA are approved.
